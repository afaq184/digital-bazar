# Digital Bazar Peshawar - Expo Go Mobile App (SDK 52)

یہ ایپلیکیشن **Expo Go (SDK 52)** کے ساتھ مکمل ہم آہنگ (compatible) کر دی گئی ہے۔

## 🔧 "Project is incompatible with this version of Expo Go" ایرر کا حل:

آپ کے موبائل میں جو **Expo Go** انسٹال ہے وہ نیا ورژن یعنی **SDK 52** ہے۔
ہم نے پروجیکٹ کی فائلوں کو **SDK 52** میں اپ گریڈ کر دیا ہے۔ اب آپ اپنے کمپیوٹر / لیپ ٹاپ کے ٹرمینل میں صرف یہ 3 کمانڈز چلائیں:

```bash
cd expo-app
npx expo install --fix
npx expo start -c
```

*(نوٹ: `-c` کیشے کو صاف کر کے نیا SDK 52 کیو آر کوڈ بنائے گا)*

---

### 📱 موبائل سے اسکین کریں:
1. اپنے موبائل میں **Expo Go** ایپ کھولیں۔
2. **"Scan QR code"** پر کلک کریں اور ٹرمینل کا نیا QR کوڈ اسکین کریں۔
3. ایپ بنا کسی ایرر کے فوری لوڈ ہو جائے گی!

---

## 🌟 Expo Go فیچرز:
1. **مکمل موبائل انٹرفیس:** پوری مارکیٹ، پروڈکٹس، اور کسٹمر، دکاندار اور ایڈمن ڈیش بورڈ موبائل پر فل اسکرین کھلیں گے۔
2. **اینڈرائیڈ بیک بٹن سپورٹ:** موبائل کا بیک بٹن دبانے پر ایپ بند ہونے کے بجائے پیچھے جائے گی۔
3. **GPS اور لوکیشن سپورٹ:** کسٹمر کی لائیو لوکیشن اور رائڈر ٹریکنگ موبائل پر براہ راست کام کرے گی۔
4. **Pull to Refresh:** اسکرین نیچے کھینچنے پر پیج ریفریش ہوگا۔
